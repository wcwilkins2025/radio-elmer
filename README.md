# Radio Elmer

A free desktop app for programming two-way radios, **powered by [CHIRP](https://chirpmyradio.com)**.
It adds guidance, licence checks and safety nets for newer hams.

- Website: https://radioelmer.org
- Manual: https://radioelmer.org/manual.html
- Downloads: see [Releases](https://github.com/wcwilkins2025/radio-elmer/releases)
- Problems and radio test reports: [Issues](https://github.com/wcwilkins2025/radio-elmer/issues/new/choose)

Radio Elmer is in beta (0.9.0). For now this repository holds the website (in `docs/`) and the
downloads. The source code will be added after the beta; the Windows downloads already include it.

Radio Elmer is a separate project from CHIRP. Please report Radio Elmer problems here, not to
the CHIRP project.
